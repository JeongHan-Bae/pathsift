# Build and package

`src/` is TypeScript. `npm run build` removes stale `dist/`, compiles with `tsconfig.json`, rewrites relative `.ts` imports to `.js`, and marks `dist/boot/cli-main.js` executable. `tsconfig.json` requires erasable TypeScript syntax so Node 24+ can execute the same source without a loader. Node 22 and 23 execute compiled JavaScript through the checkout launcher.

The npm `pathsift` bin is `./dist/boot/cli-main.js`. `prepack` rebuilds before an ordinary `npm pack` or publication. `package.json` allowlists `dist/`, `README.md`, `LICENSE`, `docs/architecture.md`, `docs/hash.md`, `pathsift.config.json`, and `global.ignore`. npm adds `package.json`. The package excludes `src/`, the checkout launcher, tests, CI, development docs, and TypeScript tooling.

Inspect the archive with `npm pack --dry-run --json`. Run `npm run stage:release` to create the Git-ignored `release-preview/` directory from a real `npm pack` tarball. It contains the `.tgz`, an extracted `package/` tree, and `pack-metadata.json`. The staging script verifies the extracted file list against npm metadata and refuses to replace a directory without its generated marker. `npm run check:package` verifies the exact file list against the generated `dist/` tree and rejects TypeScript source in the archive. `npm run test:package` makes a real tarball, installs it in a temporary consumer project with production dependencies, checks the installed bin target, and runs the per-command BDD suite against that installation.

The CLI loads `pathsift.config.json` and `global.ignore` relative to the installed package root. The shipped config must explicitly declare the supported `hashVersion` and positive `bufferLimitBytes`. Export data is buffered in memory at or below the configured visible-file byte limit and written directly above it; a failed output is removed or reset to its originally empty state. `pathsift nano` requires write access to the installed package directory; users who need it should install under a user-writable npm prefix. Other commands can read a system-owned installation.
